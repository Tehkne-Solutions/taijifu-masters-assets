# Taijifu Masters Assets

Repositório oficial de catálogo, manifests e governança dos packs binários do **Taijifu Masters**.

## Responsabilidade

Este repositório armazena somente metadados versionados e documentação dos assets. Os arquivos binários pesados são publicados em **GitHub Releases**.

- catálogo dos packs;
- manifests e checksums;
- notas de versão;
- Asset Vault;
- contratos de compatibilidade com o jogo;
- documentação de importação.

## Não armazenar no histórico Git

- ZIPs de packs;
- PNGs de produção;
- PSD/Krita/Blender;
- vídeos;
- atlas binários pesados.

## Convenção de release

```text
Tag: assets-pack-XX-vMAJOR.MINOR.PATCH
Arquivo: PACK_XX_NOME_FINAL_vMAJOR.MINOR.PATCH.zip
```
